# Future roadmap

Ordered by what unblocks real use first.

1. **Official curriculum.** Ingest `Degree_Audit_2028.xlsx`, resolve the discrepancies with the Registry, review it in-app, and confirm C pass marks. Real students then get standings.
2. **Production hardening.** Admin multi-factor authentication, a data-retention policy for audit logs and messages, a paid Render instance (no sleeping), Atlas backups, and an independent security and accessibility review.
3. **Notifications.** SMTP for temporary passwords and message copies; Firebase push notifications on mobile, with deep links into the inbox.
4. **Store release.** Signing keys, a university-owned app ID and bundle ID, Play Store and App Store listings.
5. **Registry workflows.** Curriculum versions with effective dates managed in-app, grade-scale and academic-calendar settings, advisor role (`ADVISOR`) with read access to advisees.
6. **Analytics.** Trend lines across more years, cohort drill-downs, scheduled report emails.
7. **Scale.** Atlas Search for names, report caching, background jobs for large imports.
